# SlothSort AI

A local-first file-organizing assistant with optional open-weight AI via Ollama. This starter version previews categories and never moves or deletes files automatically.

## Run
`python -m pip install -r requirements.txt`
`streamlit run app.py`

See app.py and slothsort_core.py. Optional AI requires Ollama and a model such as `gemma3:1b`.
